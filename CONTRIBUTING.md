# Contributing

Thanks for helping improve a Local Task Repo project. Everyone taking part is expected to follow the [code of conduct](CODE_OF_CONDUCT.md).

- **Questions and ideas** are welcome in [LoTaR Discussions](https://github.com/localtaskrepo/lotar/discussions), including questions about autospec and installation.
- **Bugs and feature requests** go in the issues of the repository they concern.
- **Pull requests** are welcome. Keep them small and focused, include tests for behaviour changes, and update the docs alongside user-facing changes. History stays linear, so rebase onto `main` rather than merging it into your branch.

Each project's own README or `CONTRIBUTING.md` describes its development setup, for example [LoTaR's contributing guide](https://github.com/localtaskrepo/lotar/blob/main/CONTRIBUTING.md).

The Homebrew tap and Scoop bucket are updated automatically by each project's release workflow. Please report problems with them, but propose changes to the release workflows in the project repositories instead.
