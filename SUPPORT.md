# Support

Thanks for using a Local Task Repo project.

- **Questions and help:** ask in [LoTaR Discussions](https://github.com/localtaskrepo/lotar/discussions/categories/q-a). Questions about autospec are welcome there too.
- **Bugs and feature requests:** open an issue in the repository of the project it concerns. For install problems with the Homebrew tap or Scoop bucket, an issue in that repository is fine.
- **Security problems:** please report them privately, as described in the [security policy](SECURITY.md).

When reporting a bug, include the version (`lotar --version` or `autospec --version`), your operating system and install method, and the steps to reproduce it.
