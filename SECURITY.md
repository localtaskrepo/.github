# Security policy

This policy applies to every repository in the [localtaskrepo](https://github.com/localtaskrepo) organization unless the repository has its own `SECURITY.md`.

## Supported versions

Each project is maintained on a single release line. Security fixes go into the next release, so please upgrade to the latest release before reporting.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through a GitHub security advisory in the affected repository (Security tab → **Report a vulnerability**), for example [LoTaR](https://github.com/localtaskrepo/lotar/security/advisories/new). If you cannot use GitHub, email [mallox@pyxzl.net](mailto:mallox@pyxzl.net).

The projects are maintained by volunteers, so responses are best-effort. You can expect an acknowledgement within a week, and we will keep you updated in the advisory until a fix is released. We are happy to credit you in the advisory and release notes.
